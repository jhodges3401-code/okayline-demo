FAQ

Is Okayline really a one-time payment?

Yes. $99 once for the Pro template, including updates. Hosting on GitHub Pages is free for public repos.

Is there a free version?

Yes. Okayline Lite is MIT-licensed on GitHub. It's a static status page you update by editing a JSON file.

Is Okayline affiliated with Atlassian?

No. It's an independent product built from scratch.
